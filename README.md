# 🌾 O Uso da Tecnologia GPS na Agricultura Sustentável

Este projeto consiste em um site interativo, bonito e bem estruturado, desenvolvido especialmente para o **Tema Agrinho**. O objetivo principal é conscientizar e informar sobre como o Sistema de Posicionamento Global (GPS) revoluciona o campo, permitindo uma produção agrícola mais eficiente, econômica e com menor impacto ambiental.


## 🎯 Objetivo do Projeto (Tema Agrinho)
Alinhado com as propostas do Programa Agrinho, o site busca conectar a inovação tecnológica à sustentabilidade no campo. Através de uma interface intuitiva, explicamos como o GPS auxilia na aplicação precisa de insumos, na redução do desperdício de combustível pelo maquinário e no monitoramento inteligente de frentes de trabalho, promovendo uma agricultura que preserva o futuro do nosso planeta.



## 🛠️ Tecnologias Utilizadas
O site foi construído utilizando as tecnologias fundamentais da web, garantindo leveza, performance e total controle sobre a estilização e acessibilidade:

* **HTML:** Estruturação semântica de todo o conteúdo do site.
* **CSS:** Estilização moderna, layout responsivo (adaptável a celulares e computadores) e transições suaves.
* **JavaScript:** Responsável pela lógica de interatividade e pelos recursos de acessibilidade.



## ♿ Recursos de Acessibilidade e Inclusão
Para garantir que o conhecimento chegue a todos de forma confortável, o site conta com recursos nativos de acessibilidade:
* **Modo Escuro (Dark Mode):** Altera a paleta de cores para tons escuros, reduzindo a fadiga visual.
* **Aumento de Letra:** Permite que o usuário aumente ou diminua o tamanho da fonte do texto para uma leitura mais agradável.
